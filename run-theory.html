English verb in focus

RUNin Swedish

The English verb RUN can describe managing an organisation, executing software, a machine functioning, liquid flowing, a supply ending or exposure to danger. Swedish normally chooses a separate verb for each meaning.

RUN is not always about movement on foot. Identify what is operating, flowing, ending or being managed.

Why RUN is difficult in Swedish

English extends run far beyond physical running: businesses, programs, engines, water, supplies and risks can all involve run.

Swedish normally states the exact process and therefore distributes these meanings across several verbs and verb phrases.

drivakörafungerarinnata slutriskera

What does RUN mean here?

Is somebody managing an organisation? → driva
Is software or a test being executed? → köra
Is a machine or system operational? → fungera
Is liquid flowing? → rinna
Is there none of something left? → ta slut
Is there a danger of an unwanted result? → riskera

Six Swedish ways to translate RUN

Each choice below expresses a different type of event. The English examples use ordinary British English, followed by the natural Swedish equivalent.

driva
manage · run a business

Use driva when run means managing or operating a company, shop, organisation or project.

She runs a small company.
Hon driver ett litet företag.
They run a restaurant in Malmö.
De driver en restaurang i Malmö.
Who runs the organisation?
Vem driver organisationen?
Swedish driva focuses on operating and taking responsibility for the activity.
köra
execute · run a program

Use köra when run refers to starting or executing a computer program, test, update or technical procedure.

Run the program again.
Kör programmet igen.
We need to run a test.
Vi måste köra ett test.
The system is running an update.
Systemet kör en uppdatering.
In British English, computer software is a program. The spelling programme is used for television, radio and organised events.
fungera
work · be operational

Use fungera when run means that a machine, engine or system is operating.

The machine is running normally.
Maskinen fungerar normalt.
Is the engine still running?
Fungerar motorn fortfarande?
Everything was running perfectly.
Allt fungerade perfekt.
Swedish gå is also common for machines: Motorn går. Fungera makes successful operation explicit.
rinna
flow · run

Use rinna when run describes water or another liquid flowing.

The water is running.
Vattnet rinner.
Tears ran down her face.
Tårarna rann nerför hennes ansikte.
Leave the tap running.
Låt kranen stå och rinna.
English often makes the container or source the subject, as in the tap is running. Swedish commonly focuses on the liquid or uses stå och rinna.
ta slut
be used up · run out

Use ta slut when run out means that a supply of milk, money, time or another resource is exhausted.

The milk has run out.
Mjölken har tagit slut.
Our money ran out.
Våra pengar tog slut.
Time is running out.
Tiden håller på att ta slut.
English commonly uses a person as subject: We have run out of milk. Natural Swedish often makes the missing resource the subject: Mjölken har tagit slut.
riskera
run the risk · risk

Use riskera when run occurs in the expression run the risk of.

You run the risk of losing everything.
Du riskerar att förlora allt.
We run the risk of being late.
Vi riskerar att komma för sent.
He ran the risk of being discovered.
Han riskerade att bli upptäckt.
The English noun phrase run the risk of normally becomes the single Swedish verb riskera.

How RUN divides into six meanings

Use the meaning of the complete expression — not the English verb by itself — to choose the Swedish equivalent.

Swedish choiceCore meaningTypical English RUN patternDiagnostic question
driva managing an organisation or business She runs a small company. Is somebody managing an organisation?
köra executing software or a procedure Run the program again. Is software or a test being executed?
fungera a machine operating correctly The machine is running normally. Is a machine or system operational?
rinna liquid flowing The water is running. Is liquid flowing?
ta slut a supply becoming exhausted The milk has run out. Is there none of something left?
riskera being exposed to a possible danger You run the risk of losing everything. Is there a danger of an unwanted result?
Important: English also has more specific verbs and expressions. The difficulty is that everyday English allows run in all six situations, whereas Swedish normally makes the semantic category more explicit.
