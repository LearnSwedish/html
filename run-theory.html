English verb in focus

RUNin Swedish

The English verb RUN can describe something continuing, executing software, a machine functioning, liquid flowing, movement on foot, or managing and directing operations. Swedish normally chooses a separate verb for each meaning.

Do not assume that RUN always means springa. Identify what is continuing, operating, flowing, moving or being directed.

Why RUN is difficult in Swedish

English extends run far beyond physical running: courses, programmes, engines, water, meetings and businesses can all involve run.

Swedish normally states the exact process and therefore distributes these meanings across several distinct verbs.

What does RUN mean here?

Does an event continue for a period of time? → pågå
Is software or a test being executed? → köra
Is a machine or system operational? → fungera
Is liquid flowing? → rinna
Is somebody moving quickly on foot? → springa
Is somebody directing a meeting or running a business? → leda

Six Swedish ways to translate RUN

Each choice below expresses a different type of event. The English examples use ordinary British English, followed by the natural Swedish equivalent.

pågå
continue · last

Use pågå when run describes an event, course, exhibition or programme continuing for a period of time.

The exhibition runs until Sunday.
Utställningen pågår till söndag.
The course runs for six weeks.
Kursen pågår i sex veckor.
The festival runs from Friday to Monday.
Festivalen pågår från fredag till måndag.
English often uses run to express duration. Swedish normally uses pågå when an organised event or activity continues over time.
köra
execute · run a program

Use köra when run refers to starting or executing a computer program, test, update or technical procedure.

Run the program again.
Kör programmet igen.
We need to run a test.
Vi måste köra ett test.
The system is running an update.
Systemet kör en uppdatering.
When translating technical tasks, Swedish frequently couples köra directly with software objects, making it the natural counterpart to executing system processes.
fungera
work · be operational

Use fungera when run means that a machine, engine or system is operating.

The machine is running normally.
Maskinen fungerar normalt.
Is the engine still running?
Fungerar motorn fortfarande?
Everything was running perfectly.
Allt fungerade perfekt.
Swedish gå is also common for machines: Motorn går. Fungera makes successful operation explicit.
rinna
flow · run

Use rinna when run describes water or another liquid flowing.

The water is running.
Vattnet rinner.
Tears ran down her face.
Tårarna rann nerför hennes ansikte.
Leave the tap running.
Låt kranen stå och rinna.
English often makes the container or source the subject, as in the tap is running. Swedish commonly focuses on the liquid or uses stå och rinna.
springa
run · move quickly on foot

Use springa when run has its basic physical meaning: moving quickly on foot.

I run every morning.
Jag springer varje morgon.
The children ran across the playground.
Barnen sprang över lekplatsen.
He is running to catch the bus.
Han springer för att hinna med bussen.
Here English and Swedish use the corresponding physical-motion verbs: run and springa.
leda
lead · manage a business or meeting

Use leda when run means directing a meeting, managing a company, running an organization or leading a project.

She runs a successful tech company.
Hon leder ett framgångsrikt teknikföretag.
He runs the family business in Lund.
Han leder familjeföretaget i Lund.
Who is running today's meeting?
Vem leder dagens möte?
English run a business or run a meeting focuses on administration, control and guidance. Swedish captures both under the versatile verb leda.

How RUN divides into six meanings

Use the meaning of the complete expression — not the English verb by itself — to choose the Swedish equivalent.

Swedish choiceCore meaningTypical English RUN patternDiagnostic question
pågå an event continuing over time The exhibition runs until Sunday. Does an event continue for a period of time?
köra executing software or a procedure Run the program again. Is software or a test being executed?
fungera a machine operating correctly The machine is running normally. Is a machine or system operational?
rinna liquid flowing The water is running. Is liquid flowing?
springa moving quickly on foot I run every morning. Is somebody moving quickly on foot?
leda directing an activity or running a business She runs a successful tech company. Is somebody managing a business or directing a meeting?
Important: English also has more specific verbs and expressions. The difficulty is that everyday English allows run in all six situations, whereas Swedish normally makes the semantic category more explicit.
