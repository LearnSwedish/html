English verb in focus

SETin Swedish

The English verb SET can describe arranging a table, adjusting a device, deciding a date, assigning a price, the sun disappearing below the horizon or releasing somebody. Swedish normally chooses a more specific verb for each event.

SET does not have one fixed Swedish equivalent. Identify what is being arranged, adjusted, decided, assigned or released.

Why SET is difficult in Swedish

English uses set across very different situations: set the table, set the alarm, set a date, set the price, the sun sets, set someone free.

Swedish normally states the exact action. The object — or, with the sun, the subject — determines which Swedish verb is natural.

What does SET mean here?

Is somebody preparing the table for a meal? → duka
Is a clock, alarm or device being adjusted? → ställa
Is somebody deciding when something will happen? → bestämma
Is somebody assigning a price? → sätta
Is the subject the sun? → gå ner
Is somebody being released from captivity? → frige

Six Swedish ways to translate SET

Each choice below expresses a different type of event. The English examples use ordinary British English, followed by the natural Swedish equivalent.

duka
lay · set the table

Use duka when set means putting plates, glasses and cutlery on a table before a meal.

Could you set the table?
Kan du duka?
She set the table for six people.
Hon dukade för sex personer.
The children are setting the table.
Barnen dukar.
Swedish duka expresses the whole activity. It does not require a direct equivalent of the English noun table.
ställa
adjust · set a device

Use ställa when set means adjusting a clock, alarm, timer or similar device.

Set the alarm for six.
Ställ väckarklockan på sex.
I set the timer for twenty minutes.
Jag ställde timern på tjugo minuter.
Have you set the clock?
Har du ställt klockan?
The related verb ställa in is common when a device is adjusted to a particular setting: ställa in ugnen på 200 grader.
bestämma
decide · set a date

Use bestämma when set means deciding a date, time or deadline.

We need to set a date.
Vi måste bestämma ett datum.
They set the meeting for Friday.
De bestämde att mötet skulle hållas på fredag.
Have you set a deadline?
Har ni bestämt en tidsgräns?
Swedish focuses on the act of deciding. Depending on context, bestämma tid or bestämma datum may be the most natural expression.
sätta
assign · set the price

Use sätta when set refers to assigning or deciding the price of something.

Who set the price?
Vem satte priset?
They set the price too high.
De satte priset för högt.
We have set the price at 500 kronor.
Vi har satt priset till 500 kronor.
The ordinary Swedish expression is sätta priset. Fastställa priset is a more formal or specialised alternative.
gå ner
set · disappear below the horizon

Use gå ner when English set describes the sun disappearing below the horizon.

The sun sets at seven.
Solen går ner klockan sju.
We watched the sun set over the sea.
Vi såg solen gå ner över havet.
The sun had already set.
Solen hade redan gått ner.
Swedish uses the movement expression gå ner. The opposite is gå upp: solen går upp.
frige
release · set someone free

Use frige when set free means releasing a person or animal from captivity or confinement.

The prisoners were set free.
Fångarna frigavs.
They set the bird free.
De frigav fågeln.
He was set free the following day.
Han frigavs dagen därpå.
In less formal everyday contexts, Swedish may also use släppa fri. Frige is the concise single-verb equivalent.

How SET divides into six meanings

Use the meaning of the complete expression — not the English verb by itself — to choose the Swedish equivalent.

Important: English also has more specific verbs and expressions. The difficulty is that everyday English allows set in all six situations, whereas Swedish normally makes the semantic category more explicit.
